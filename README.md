# 香蕉起始页(Chrome 新标签页扩展)v1.4.0

一个覆盖 Chrome 新标签页的主页:**实时同步 Chrome 收藏夹(卡片式 + DeepSeek 一句话简介)**、可自定义快捷方式、多引擎搜索、时钟/天气/日历/宠物/白噪音/热榜/股票/梦想之车等组件,支持「网格 / 清爽」双模式切换。

## 功能

### 搜索与快捷方式
- 🔍 搜索框:百度 / 必应 / Google / GitHub / 知乎 / B站 / 抖音 / 微博等多引擎切换,支持自定义添加 / 拖拽排序 / 设当前引擎
- 🕘 搜索历史(去重,最多 10 条)与联想建议(跟随当前引擎,GBK/UTF-8 自动识别)
- 📌 右侧快捷方式网格:分页 + 跨页拖拽排序 + 右键编辑/删除 + 自定义添加,每页数量随窗口高度自适应
- 🖼️ 快捷方式显示网站 favicon,失败回退通用地球图标

### 书签与 AI 简介
- 📁 实时收藏夹:通过 `chrome.bookmarks` API 读取收藏夹,按文件夹分组展示;增/删/改名/移动实时同步,无需刷新
- 🤖 AI 简短标题 + 一句话简介:一次 DeepSeek 调用同时生成 ≤14 字标题与 ≤30 字描述,结果本地缓存,同一网址不重复生成
- 🖼️ 悬浮网页预览:鼠标悬停卡片弹出目标网页 iframe 实时预览(预先检测 X-Frame-Options / CSP 是否允许嵌入,禁止嵌入时提示打开原网页)
- 🛠️ 维护卡片:卡片右下角「⋯」弹窗可手动修改标题/简介、AI 重新生成、删除书签;手动维护过的书签不会被自动生成覆盖
- ✨ 一键 AI 生成 + 「打开主页时自动生成」开关(串行队列,进度显示在右上角)

### 左栏组件页(圆点翻页,每卡可调 1/4–4/4 档位、显示/隐藏、拖拽排序)
- 🕐 时钟 + 日期 + 按时段变化的问候
- 📅 日历:当月天数 + 农历(1900-2100)+ 节气 + 法定节假日/调休(holiday-cn 数据,1/4 档为本周视图)
- 💬 名言警句(每日一句,点击换一句;开源 Hitokoto 接口 + 内置兜底;可 AI 释义)
- 🗺️ 位置地图:IP 定位 + 高德瓦片拼接,点击卡片可用浏览器精确定位
- 🌤️ 天气:Open-Meteo 数据 + emoji 图标,未来 6 天预报;可开启跟随天气的页面粒子效果(晴/云/风/雨/雪)
- 🐾 桌面宠物(vscode-pets 精灵,MIT):随机行为 + 切换 / 喂食 / 拖拽
- 🎵 白噪音:本地音效循环播放(雨/海/火/风/溪流)+ 拾音频谱图,刷新续播、隐藏/切清爽自动暂停
- 📈 股票行情:腾讯行情接口,30s 刷新,自选股管理(搜索添加 / 拖拽排序 / 删除)+ A股大盘云图弹窗
- 🖥️ 系统监控:CPU / 内存(Chrome system API,2s 采样)
- 🔥 今日热榜:百度 / 抖音 / 头条 / B站 / 知乎,10 分钟自动刷新
- 🃏 每日扑克牌:按日期种子确定性随机三张,当日不变、次日更换
- 🚗 梦想之车:汽车之家选车(品牌/车系/款型联动下拉,仿 antd Select)+ VR 全景看车(360° 序列图,自动/手动旋转),上次选择自动保存
- 📊 访问活跃度:GitHub 风格贡献日历(最近半年/一年),每次打开主页计一次
- 🧭 八卦罗盘:后天八卦 + 太极图,今日卦/随机起卦/AI 解卦,☯ 打开 23 环综合罗盘演化图

### 模式与外观
- 🔀 网格 / 清爽双模式:清爽模式只保留搜索栏(聚焦时背景蒙版磨砂),刷新时**零网格资源加载**(组件脚本/书签数据/网络接口/媒体文件全部门控,见 AGENTS.md)
- 🎨 背景:渐变 / 纯色(调色盘)/ Bing 每日壁纸 + 随机图(右下角风车切换)
- 🧊 五区域透明度与磨砂度可调(搜索栏/左侧组件/收藏夹/快捷方式/主卡片),清爽模式蒙版可调
- ⚙️ 组件页签:卡片高度档位 / 显示隐藏 / 全局顺序拖拽排序,均可恢复默认
- 💾 配置导出/导入(JSON):快捷方式、搜索引擎、AI 设置、外观、背景、自选股、组件布局等全量跟随

## 安装(一次性)

1. 打开 Chrome,访问 `chrome://extensions`;
2. 打开右上角「开发者模式」;
3. 点击「加载已解压的扩展程序」,选择本文件夹 `D:\test1\banana-home`;
4. `Ctrl+T` 开新标签页即可看到主页。

> 已安装过旧版本?在扩展页点该扩展的「刷新」按钮即可升级(需重新授权新增的联网权限)。

## 配置 DeepSeek API Key(生成简介/释义/解卦必需)

1. 注册 [DeepSeek 开放平台](https://platform.deepseek.com)(新用户通常赠送额度);
2. 左侧「API Keys」→ 创建并复制一个 `sk-…` 形式的 Key;
3. 打开主页 → 右上角 **⚙️ 设置** → AI 页签 → 粘贴 Key → 保存;
4. 点「✨ 一键 AI 生成」即可。

> Key 仅保存在本机浏览器(`chrome.storage.local`),不会上传到任何第三方;简介通过 DeepSeek 官方 API 生成,按 token 计费。

## 结构

```
banana-home/
├── manifest.json       # MV3:newtab 覆盖 + bookmarks/storage/favicon/geolocation/system + 全站联网权限
├── background.js       # service worker:书签采集与实时监听 + 网页抓取 + DeepSeek 生成与缓存
│                       #   + IP 定位/天气 + 梦想之车代理 + 壁纸/热榜/接口检测
├── index.html          # 页面结构(搜索/三栏/设置与各管理弹窗;仅引 3 个基础脚本)
├── map.html            # 位置地图 iframe 页(高德瓦片拼接)
├── css/style.css       # 全部样式(毛玻璃 + 双模式 + 组件)
├── js/
│   ├── gridgate.js     # 网格资源门控(全模式加载):模式恢复 + 任务队列 + 共享常量/注册器
│   ├── activity.js     # 访问活跃度(全模式加载,记录访问)
│   ├── main.js         # 页面逻辑:搜索/书签/快捷方式/设置/模式切换/门控注入组件脚本
│   └── 组件脚本(仅网格模式动态注入):calendar / colpager / pet / music / monitor
│       / hot / stock / dreamcar / poker / bagua / compass
├── img/                # 图标、宠物 GIF、四象 SVG、风车、收款码
└── audio/              # 白噪音本地音效(雨/海/火/风/溪流)
```

> 开发与改动的**硬性规范**(资源门控、UI 风格、存储约定等)见 `AGENTS.md`,改动前务必阅读。

## 工作原理

```
Chrome 书签 ──chrome.bookmarks API──▶ background.js
     ▲                                      │ ① 写入 session(书签列表)
     │ 增/删/改/移事件                        ▼
     └──── 实时 ───────▶ 新标签页(storage.onChanged 重渲染)

生成简介:
  background.js ──fetch──▶ 目标网页 → 提取正文(≤2500字)
       └─▶ DeepSeek API(deepseek-chat)─▶ 标题 + 一句话描述
       └─▶ 缓存 chrome.storage.local(同一 URL 不重复调用)

悬浮预览:
  页面 iframe 直接加载目标网址(预先 checkFrameable 检测 X-Frame-Options/CSP)
```

## 自定义

- 搜索引擎:设置 → 引擎管理(名称 / 链接 `%s` 占位 / 图标),或修改 `js/main.js` 的 `DEFAULT_ENGINES`
- 默认快捷方式:修改 `js/main.js` 的 `DEFAULT_QUICK`
- 配色 / 背景动画:`css/style.css` 顶部 `:root` 变量与 `.bg`
- 简介长度:修改 `background.js` 的 `MAX_TEXT_LEN` 与 system prompt 中的字数要求
- 卡片默认档位:修改 `js/gridgate.js` 的 `window.DEFAULT_CARD_HEIGHTS`(清爽模式设置窗口也要读,勿放进组件脚本)

## 已知限制

- 少数网站有反爬(403)或纯 JS 渲染(SPA),抓取不到正文时该网站不会生成简介,卡片显示「无法生成简介,请手动维护」;
- 悬浮预览依赖站点允许 iframe 嵌入,禁止嵌入的站点显示提示而非预览;
- 白噪音自动续播受浏览器自动播放策略限制(需用户手势);
- 直接双击 `index.html` 打开不会生效,请以扩展方式加载。

## 常见问题

- **打开新标签页还是原来的?** 检查扩展是否启用,确认没有其他扩展占用 newtab 覆盖;
- **简介一直显示"生成中"?** 检查 API Key 是否填写正确、账户是否有余额;
- **书签图标不显示?** 部分网站未提供 favicon,自动回退为通用地球图标;
- **清爽模式还有网络请求?** 刷新页面即可保证零网格资源;会话内由「清爽 → 网格」切换会按门控恢复数据(组件定时器已带清爽模式守卫)。
